# CodeAlpha Data Visualization Project

## Project Overview

This project is completed as part of the CodeAlpha Data Analytics Internship.

The objective of this project is to visualize the Sample Superstore dataset using Python and create meaningful charts to understand sales, profit, and business trends.

## Dataset

The project uses the Sample Superstore dataset containing information about orders, customers, products, sales, discounts, and profit.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Excel Dataset
- VS Code

## Visualizations Created

1. Sales by Category
2. Profit by Region
3. Sales by Sub-Category
4. Monthly Sales Trend

## Key Insights

- Technology generated the highest total sales among the three categories.
- The West region had the highest total profit.
- Chairs and Phones were among the highest-selling sub-categories.
- Monthly sales showed noticeable variation throughout the dataset period.
